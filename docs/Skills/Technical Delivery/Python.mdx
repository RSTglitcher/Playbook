# 📘 Python Development & Scripting

:::tip

## Python Development & Scripting

**What is it?** 
A structured software engineering skill focused on building clean, readable, and maintainable applications using Python's high-level syntax, dynamic typing, extensive ecosystem, and versatile programming paradigms.

#### 📚 Related Theory & Practice References
* Theory — Programming language paradigms, dynamic vs. static typing, and runtime interpretation.
* Practice — Package management (`pip`, `Poetry`), virtual environments, and automation scripting.
:::

## 🧭 When is it Used?

| When to Use | When Not to Use |
| :--- | :--- |
| • Building backend web services (FastAPI, Django), data pipelines (Pandas, NumPy), and automation scripts. • Rapidly prototyping software architectures or writing orchestration glue code across microservices. • Performing log parsing, text transformation, and file system automation tasks. | • Extreme high-performance, low-latency systems requiring manual memory management and native compilation. • Simple browser-based frontend interfaces (where JavaScript or WebAssembly is required). |

---

## 💡 What Value Does It Bring?

* **Maximizes Developer Velocity:** Features clean, English-like syntax that drastically reduces boilerplate and accelerates time-to-market.
* **Vast Ecosystem Integration:** Grants instant access to hundreds of thousands of pre-built packages via PyPI for data science, AI, and backend development.
* **Versatile Problem Solving:** Seamlessly supports procedural, object-oriented, and functional coding styles within a single codebase.

---

## 🧠 Core Concepts

| Concept / Mechanism | Plain English Explanation | Execution Impact |
| :--- | :--- | :--- |
| **Dynamic Typing & Duck Typing** | Variables do not require explicit type declarations; types are resolved at runtime based on object behavior. | Allows rapid script authoring, though it requires disciplined testing to prevent silent runtime type errors. |
| **Context Managers (`with`)** | Resource allocation wrappers that handle automatic setup and teardown (e.g., files, database connections). | Prevents resource leaks and dangling file descriptors by ensuring cleanup happens safely. |
| **List & Dict Comprehensions** | Concise, readable shorthand syntax for creating and filtering collections from iterables. | Replaces verbose multi-line `for` loops with optimized, single-line collection transformations. |

---

## 📋 Common Patterns

1. **Phase 1: Environment Setup & Isolation** — Create isolated virtual environments (`python -m venv venv`) and manage package dependencies using `pip` or Poetry.
2. **Phase 2: Modular Scripting & Data Modeling** — Structure code using classes, functions, and standard PEP 8 naming conventions.
3. **Phase 3: Robust Execution & File Handling** — Utilize context managers and explicit exception handling (`try/except`) for resilient file I/O and API requests.

## 🛠️ Practical Tips & Templates

> **Template / Artifact Example:** Python Syntax Fundamentals and Execution Patterns.

```python
# 1. Basic Data Types & Variable Declarations
count: int = 0
message: str = "Hello World"
is_active: bool = True
data: dict = {"role": "Engineer", "level": 5}

# 2. Basic Function (Hello World)
def greet(name: str) -> str:
    return f"Hello, {name}!"

# 3. List Comprehension
squares: list[int] = [x * x for x in range(10)]

# 4. Context Managers for File Operations
with open("config.txt", "w") as f:
    f.write(message)

# 5. Simple Class Definition
class Greeter:
    def __init__(self, prefix: str) -> None:
        self.prefix = prefix

    def say_hello(self, name: str) -> str:
        return f"{self.prefix}, {name}!"

# Execution
instance = Greeter("Welcome")
print(instance.say_hello("Python Developer"))

```

:::warning

### Pitfalls & Edge Cases

* **Common Mistake:** Using mutable default arguments (like lists or dicts) in function signatures, which retain state across multiple function calls unexpectedly.
* **Pro Tip:** Always isolate your project dependencies inside a virtual environment (`venv`) to avoid polluting your global system Python environment and breaking package versions.
:::
