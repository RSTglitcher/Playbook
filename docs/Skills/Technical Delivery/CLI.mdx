# 📘 Command-Line Interface (CLI) Automation

:::tip

## Command-Line Interface (CLI) Automation

**What is it?**
A structured technical skill focused on interacting with operating systems and developer toolchains via text-based command-line interfaces, executing commands, configuring flags, and automating workflows.

#### 📚 Related Theory & Practice References
* Theory — Process execution models, standard streams (stdin, stdout, stderr), and shell environments.
* Practice — Terminal navigation, CLI utility flags, and automation script authoring.
:::

## 🧭 When is it Used?

| When to Use | When Not to Use |
| :--- | :--- |
| • Executing build toolchains, package managers (npm, pip, brew), and cloud infrastructure CLIs (AWS, Docker, Git). • Automating repetitive file manipulations, server deployments, and local development environments. • Troubleshooting system processes, environment variables, and log streams via terminal tools. | • Building complex graphical user interfaces (GUIs) or desktop application windows. • Authoring rich text documents, spreadsheets, or visual graphic layouts. |

---

## 💡 What Value Does It Bring?

* **Maximizes Execution Speed:** Allows developers to trigger complex builds and system actions instantly via keyboard shortcuts and direct commands.
* **Enables Automation:** Forms the backbone of CI/CD pipelines, shell scripts, and automated infrastructure deployments.
* **Reduces Overhead:** Bypasses heavy graphical interfaces to interact directly with system kernels, servers, and build toolchains.

---

## 🧠 Core Concepts

| Concept / Mechanism | Plain English Explanation | Execution Impact |
| :--- | :--- | :--- |
| **Standard Streams (Streams 0, 1, 2)** | Standard input (`stdin`), standard output (`stdout`), and standard error (`stderr`) channels for data flow. | Enables redirection and piping (`>`) of command outputs into other tools or log files. |
| **Flags, Options & Arguments** | Modifiers (`-f`, `--verbose`) and target targets (`filename.txt`) passed to a CLI command to alter behavior. | Provides fine-grained control over how execution commands run and which assets they target. |
| **Environment Variables** | Dynamic key-value pairs stored in the shell environment (e.g., `PATH`, `NODE_ENV`) influencing process behavior. | Configures runtime settings securely without hardcoding secrets or configurations into source files. |

---

## 📋 Common Patterns

1. **Phase 1: Environment & Path Verification** — Check current working directory, verify CLI tool installations, and inspect active environment variables.
2. **Phase 2: Command & Flag Execution** — Run primary commands with appropriate options, flags, and file targets.
3. **Phase 3: Stream Redirection & Pipeline Chaining** — Combine commands using pipes (`|`) or redirect output logs to target files for debugging.

### Keyboard Shortcuts
```shell
# Opening Files
vi filename           # Open or create file
vi -R filename        # Open file read-only
view filename         # Open existing file read-only

# Insert / Append Modes
i     # insert before cursor
I     # insert at beginning of line
a     # append after cursor
A     # append at end of line
o     # new line below cursor (enter insert mode)
O     # new line above cursor (enter insert mode)
@     # input mode (macro execution)
R     # enter replace/overtype mode

# Navigation
:#       # go to line # (example :8 to go to line 8)
gg       # move to top of file
G        # move to end of file
4gg      # move to line 4
^        # beginning of current line
$        # end of current line

# Deleting / Changing Text
x        # delete current character
nx       # delete n characters
dd       # delete current line
ndd      # delete n lines
dw       # delete current word
ndw      # delete n words
D        # delete from cursor to end of line
r        # replace a single character
.        # repeat last command

# Undo / Save / Quit
u        # undo last change
U        # undo all changes on current line
ZZ       # save and exit
:w       # write buffer to files
:wq      # write and quit
:x       # write and quit
:q       # quit if no changes
:q!      # quit without saving
```
### Terminal Interaction
```shell
Ctrl + C # Interrupt running process
Ctrl + Z # Suspend process (send to background)
Ctrl + D # End-of-file / Exit shell
Ctrl + R # Reverse search command history
Ctrl + L # Clear terminal screen (like clear)
Ctrl + A # Move cursor to beginning of line
Ctrl + E # Move cursor to end of line
Ctrl + U # Delete from cursor to start of line
Ctrl + K # Delete from cursor to end of line
Ctrl + W # Delete word before cursor
Ctrl + Y # Paste text deleted by Ctrl+U / Ctrl+K / Ctrl+W
Ctrl + T # Swap the last two characters before cursor
Alt + B # Move backward one word
Alt + F # Move forward one word
Alt + D # Delete the word after the cursor
Ctrl + _ # Undo previous edit in the shell
Tab # Auto-complete files, directories, commands
!! # Repeat last command
!n # Repeat command from history at line n
!string # Repeat last command starting with string

```

### Commands
```shell
# Navigation & Context
/           # Root directory
.           # Current directory
..          # Parent directory
~           # Home directory

pwd         # Print working directory
ls          # List directory contents
ls -l       # Long listing format
ls -a       # Include hidden files
ls -la      # Long listing including hidden files
ls -lh      # Human-readable file sizes
ls -R       # Recursive listing
ls -t       # Sort by modification time
ls -S       # Sort by file size
tree        # Display directory tree (if installed)

cd          # Change to home directory
cd /path    # Change directory
cd ..       # Move up one directory
cd -        # Switch to previous directory

# Help & Discovery
man command     # Manual page for a command
command -h     # Command help (if supported)
which command  # Path to executable

# File & Directory Management
mkdir dir               # Create directory
mkdir -p a/b/c          # Create nested directories
touch file.txt          # Create empty file
cp src dest             # Copy file
cp -r src dest          # Copy directory recursively
mv src dest             # Move or rename
rm file.txt             # Delete file
rm -r dir               # Delete directory recursively
rm -i file.txt          # Prompt before delete

# File Inspection
cat file.txt            # Output file contents
less file.txt           # Paged file viewer
more file.txt           # Basic pager
head file.txt           # First 10 lines
head -n 5 file.txt      # First 5 lines
tail file.txt           # Last 10 lines
tail -n 5 file.txt      # Last 5 lines
tail -f file.txt        # Follow file (logs)

# Search & Pattern Matching
grep "text" file.txt        # Search text in file
grep -i "text" file.txt     # Case-insensitive search
grep -r "text" .            # Recursive search
grep -v "text" file.txt     # Invert match
grep -w "text" file.txt     # Whole-word match
grep -c "text" file.txt     # Count matches
grep -n                     # Show line number
grep -B                     # Show lines before match
grep -A                     # Show lines after match
grep -C                     # Show context

find . -name file.txt       # Find file by name
find . -type f              # Find files only
find . -type d              # Find directories only
find . -size +10k           # Files larger than 10KB
find . -mtime -2            # Modified in last 2 days
find . -exec rm {} \;       # Execute command on results

# Pipes & Redirection
command1 | command2         # Pipe output
command > file.txt          # Redirect stdout
command >> file.txt         # Append stdout
command 2>&1                # Redirect stderr to stdout

# Text Processing
wc file.txt                 # Line, word, byte count
wc -l file.txt              # Line count
wc -w file.txt              # Word count
wc -c file.txt              # Byte count
sort file.txt               # Sort lines
sort -r file.txt            # Reverse sort
uniq file.txt               # Remove adjacent duplicates
uniq -d file.txt            # Show duplicates only
cut -c1-5 file.txt          # Character range
tr a-z A-Z                  # Translate characters
cmp file1 file2             # Binary file comparison
diff file1 file2            # Line-by-line diff

# Permissions & Ownership
chmod 755 file              # Set permissions
chmod -R 600 dir            # Recursive permissions
chmod u+x file              # User executable
chmod g-w file              # Remove group write
chmod o-r file              # Remove other read
chown user:group file       # Change ownership
ls -ld dir                  # Show directory permissions

# Processes & Jobs
ps                          # Process snapshot
ps -f                       # Full process listing
ps aux                      # All processes
top                         # Real-time process view
jobs -l                     # Background jobs

kill PID                    # Terminate process
kill -19 PID                # Pause process
kill -18 PID                # Resume process

fg %jobid                   # Bring job to foreground
bg %jobid                   # Resume job in background

# Disk & System Information
df -h                       # Disk space usage
du -sh dir                  # Directory size
uname                        # System info
uptime                        # System uptime
hostname                      # Host name
env                           # Environment variables
printenv                       # Environment variables

# Networking
ping host                   # Test connectivity
curl -O url                 # Download file
ssh user@host               # SSH connection
scp file user@host:/path    # Secure copy
traceroute host             # Network path
ifconfig                    # Network interfaces
arp -a                      # ARP table


# Archives & Compression
tar -cvf archive.tar dir    # Create tar archive
tar -xvf archive.tar        # Extract tar archive
gzip file                   # Compress
gunzip file.gz              # Decompress

# History & Session Control
history                     # Command history
history 20                  # Last 20 commands
!!                          # Repeat last command
!prefix                     # Run last command starting with prefix
clear                       # Clear terminal

# Search
/searchString      # search forward for a string
?searchString      # search backward for a string
/word              # highlight a particular word

# User Commands
who                 # list users currently logged in
finger              # display detailed info about users
users               # display logged-in users in one line
id                  # show current user's UID, GID, and group memberships

# System Commands
du                  # disk usage of files/folders
hostname            # display system hostname

# Additional Useful Utilities
which               # display path to executable for a command
basename            # strip directory path and return filename
dirname             # strip filename and return directory path
readlink -f         # display canonical absolute path of file
sleep 5             # pause execution for 5 seconds (can be any number)


# Display / Sorting / Comparison
clear               # clear terminal screen
echo "text"         # print text or variable values to terminal
sort filename       # sort lines of a file alphabetically
uniq filename       # remove duplicate consecutive lines
diff file1 file2    # compare two files line by line
cmp file1 file2     # compare two files byte by byte

# Filters / Text Transformation
cut -c1-5 filename  # extract specific character positions or fields
tr 'a-z' 'A-Z'      # translate characters, e.g., lowercase to uppercase
```




:::warning

Pitfalls & Edge Cases
Common Mistake: Executing destructive commands (like rm -rf or database drops) without validating target paths or checking current working directories.

Pro Tip: Always use flags like --dry-run or inspect command paths with which [command] before running unfamiliar production deployment scripts.
:::
