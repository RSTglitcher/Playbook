## 🚨 Operational Triage Snapshots

:::danger
Quick-reference diagnostics for common platform failures:
:::

| Symptom / Telemetry | Root Cause | What to Check | Immediate Action |
| --- | --- | --- | --- |
| **Connection Timeout / 504** | Network congestion or target service down. | • DNS resolution 

 • VPN / VPC status | • Test connection via curl 

 • Escalate if upstream is unreachable. |
| **Authentication Expired / 401** | Token TTL expired or missing credential profile. | • Local credential store 

 • Token timestamp | • Re-authenticate via CLI login. 

 • Refresh auth tokens. |
| **Rate Limit Exceeded / 429** | High query concurrency or missing pagination. | • Request frequency 

 • Query complexity score | • Implement request batching or exponential backoff. |
