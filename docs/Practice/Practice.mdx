## 🚨 Operational Triage & Diagnostics

:::danger
Common symptoms, root causes, and immediate triage steps for this platform:
:::

| Symptom / Telemetry | TLDR Root Cause | What to Check | Action to Propose |
| --- | --- | --- | --- |
| **Connection Timeout / 504 Gateway Error** | Network congestion, firewall blocking, or target service down. | • Check DNS resolution<br>

<br>• Verify VPN / VPC peering status | • Test connection via curl<br>

<br>• Escalate to platform infra team if upstream is down. |
| **Authentication Expired / 401 Unauthorized** | Token TTL expired or missing credentials profile. | • Check local credential store<br>

<br>• Review token expiration timestamp | • Re-authenticate via CLI login command.<br>

<br>• Refresh API tokens. |
| **Rate Limit Exceeded / 429 Too Many Requests** | Query concurrency too high or missing request pagination. | • Review client request frequency<br>

<br>• Check query cost / complexity score | • Implement request batching or exponential backoff retry logic. |
