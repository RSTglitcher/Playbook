# 📘 Jenkins CI/CD Automation Server

:::tip

## Jenkins CI/CD Automation Server

**What is it?** 
Jenkins is an open-source automation server used to build, test, and deploy software. It powers CI/CD pipelines, integrates with a wide ecosystem of plugins, and automates complex multi-stage engineering workflows.

### 📚 Related Theory References
* Workflows & Orchestration — Core pipeline architectures, release gating, and build runner models.
:::

## 🧭 When to Use It

| When to Use | When Not to Use |
| :--- | :--- |
| • Complex, highly customizable CI/CD build and deployment pipelines. • On-premise or self-hosted enterprise automation environments. • Multi-team shared automation servers requiring robust plugin integrations. | • Lightweight, repository-native workflows where simpler runners (GitHub Actions) suffice. • Fully managed cloud-native CI/CD solutions without infrastructure overhead. • Purely serverless or ephemeral-only build pipelines. |

## 🚀 Getting Started & Prerequisites

What prerequisites, dependencies, or initial configurations are required before interacting with Jenkins?
1. **Local Environment:** Network client tools installed locally (`curl`, `git`) and authorized access keys.
2. **Configuration Setup:** Pipeline-as-code definitions (`Jenkinsfile`), designated build agent labels, and repository webhook configurations.

---

## 🔑 Tool Requirements

* **Access URL / Portal:** Jenkins master controller dashboard URL (e.g., `https://jenkins.internal.enterprise.com`).
* **Authentication Method:** Corporate Single Sign-On (SSO / LDAP) or User API Tokens generated via the Jenkins dashboard configuration.
* **Initial Setup Check:** Verify controller availability and pipeline queue health using initial API health checks before triggering manual builds.

## 📋 Common & Useful Workflows

```bash
# 1. Verify Jenkins controller reachability via the REST API
curl -s [https://jenkins.internal.enterprise.com/api/json](https://jenkins.internal.enterprise.com/api/json) | jq '.jobs[] | .name'

# 2. Trigger a parameterized build job via curl and user API token
curl -X POST [https://jenkins.internal.enterprise.com/job/my-service-pipeline/build](https://jenkins.internal.enterprise.com/job/my-service-pipeline/build) \
  --user "username:api_token"

# 3. Fetch console output logs for a specific build run
curl -s [https://jenkins.internal.enterprise.com/job/my-service-pipeline/42/consoleText](https://jenkins.internal.enterprise.com/job/my-service-pipeline/42/consoleText)

# 4. Validate agent executor capacity and active queue status
curl -s [https://jenkins.internal.enterprise.com/computer/api/json](https://jenkins.internal.enterprise.com/computer/api/json) | jq '.busyExecutors'

```

## 🚨 Operational Triage Snapshots

:::danger
Quick-reference diagnostics for common Jenkins platform failures:
:::

| Symptom / Telemetry | Root Cause | What to Check | Immediate Action |
| --- | --- | --- | --- |
| **Server Down / 504 Gateway** | Jenkins controller service stopped, JVM out-of-memory crash, or host down. | System/pod status logs, heap usage metrics, and host CPU utilization. | Restart the Jenkins service or container pod; inspect memory allocation flags. |
| **Pipeline Failure / Build Error** | Broken build steps, missing credentials, or environment mismatch. | Jenkins console output logs, pipeline configuration steps, and secret bindings. | Fix failing build commands, update credential bindings, or validate build agents. |
| **Jobs Stuck in Queue** | Build queue backlog or blocked/offline build agents. | Queue status page, agent node online state, and executor slot availability. | Free busy executors, bring offline agents back online, or spin up new capacity. |
| **Plugin Compatibility Failure** | Outdated or conflicting plugin versions causing UI or job errors. | Plugin manager update center status and server error logs. | Update plugins to compatible versions or roll back problematic extensions. |
